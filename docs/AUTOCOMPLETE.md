# 식재료 자동완성

2026-10-17 · 앱 1.0.3+4

## 사용 흐름

새 식재료 등록의 이름에 `서울우`, `우유`, `계란`, `당근` 또는 이전에 등록한 이름을 입력한다. 대표 이미지·이름·용량·출처가 있는 제안을 최대 5개 보여준다. 선택하면 이름과 등록 수량·단위를 채운다. 수량을 수정할 수 있고, 검색 결과가 없어도 직접 입력해 등록할 수 있다.

선택한 제품은 이번에 새로 산 재고다. 이전 기록의 남은 수량 대신 **최초 등록 수량**을 가져온다. 소비기한과 가격은 제안 데이터에 포함하지 않으며, 다른 제안을 선택하면 화면에서 입력한 소비기한·구매금액도 비워 새 구매 기준으로 확인하도록 한다. 구매금액은 계속 선택 입력이며, 비워두면 SQL NULL과 ‘금액 미입력’을 유지한다.

처리 기록이 있는 기존 재료를 수정하는 화면에는 자동완성을 제공하지 않는다. 기존 이름·소비기한 수정, 수량·가격 제한과 기록 없는 재료만 삭제하는 정책은 그대로다.

## 데이터와 검색

- 앱에 포함한 22개 선택지: 서울우유 저지방 3개 용량과 일반 식재료 19개.
- 기기에 저장된 최근 등록 200개까지 조회한다. 재고가 모두 처리된 식재료도 재등록에 활용한다.
- 등록일 내림차순, 같은 날에는 저장 순서의 역순으로 조회한다. 삭제된 식재료는 다음 조회에서 제외된다.
- 등록 화면이 열릴 때 이력을 한 번 불러온다. 입력 중에는 정규화된 메모리 목록만 검색한다.
- 공백·영문 대소문자를 정규화하고 이름·별칭으로 검색한다. 정확 일치, 접두어, 별칭 접두어, 부분 일치 순으로 정렬한다.
- 같은 이름·단위 종류·수량의 중복은 최근 이력을 우선한다. 이력이 기본 목록을 대체해도 계란/달걀 같은 별칭은 보존한다.
- 이력 읽기에 실패해도 기본 목록과 직접 입력을 제공한다. ‘이전 기록 재시도’로 다시 불러올 수 있다.
- 서버, 외부 상품 API, 네트워크 이미지 다운로드, 새 패키지를 추가하지 않았다.

## 수량과 이미지의 의미

일반 식재료의 양은 수정 가능한 **기본 입력량**이다. ‘당근 1개’, ‘두부 300g’ 등이 특정 제조사의 포장 규격이라는 뜻은 아니다. 상품 규격과 사용자 구매 개수 곱하기 기능을 별도로 추가한 것은 아니며, 현재 수량 입력이 전체 등록량을 나타낸다.

이미지는 앱에서 직접 그리는 대표 벡터 일러스트다. 실제 상품 포장 사진이나 사용자 사진으로 표시하지 않는다. 제안 목록과 선택 안내에 ‘대표 이미지’를 표시한다. 상세 화면에서는 저장된 식재료 이름에 맞춰 같은 대표 그림을 다시 그린다. 별도 이미지 ID·파일·DB 컬럼을 저장하지 않으며, 이름을 바꾸면 대표 이미지도 이름 기준으로 바뀐다. 사진 첨부 기능은 후속 범위다.

## 대표 상품 근거

서울우유 나100% 저지방우유의 200mL·500mL·1000mL 규격은 [제조사 제품 정보](https://www.seoulmilk.co.kr/enterprise/product/product_view.sm?nmNo=10000000000586)를 2026-10-17에 확인했다. 제품명과 용량만 사용하며 해당 사이트의 사진·광고 문구·가격은 포함하지 않는다. 출시된 모든 상품을 검색하는 데이터베이스는 아니다.

## 변경 파일

- `lib/domain/food_catalog.dart`: 대표 목록, 별칭, 정규화·정렬·중복 제거, 입력 가능한 단위 선택.
- `lib/ui/ingredient_autocomplete.dart`: 입력·제안 목록·이력 읽기·실패 재시도.
- `lib/ui/food_illustration.dart`: 대표 일러스트.
- `lib/data/inventory_repository.dart`: 기존 foods에서 제한된 최근 이력 조회.
- `lib/main.dart`: 신규 등록 연결, 선택 값 적용과 구매 정보 초기화, 상세 이미지.
- `test/food_catalog_test.dart`, `test/autocomplete_repository_test.dart`, `test/autocomplete_widget_test.dart`: 검색·저장·화면 검증.
- `tool/preview.dart`: 자동완성 제안·선택·이력 화면 캡처.

앱 ID, 데이터베이스 이름·버전·테이블, Food 모델, 과거 처리 기록과 누적 금액 계산은 변경하지 않았다.
