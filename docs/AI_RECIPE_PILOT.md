# 실제 추천 테스트 운영

대상은 tpugkdsqrsiucnjyakqx 프로젝트다. 공개 운영 승인 플래그는 false이며, RECIPE_PILOT_MODE=true인 경우 Auth 검증과 서버 허용 목록을 통과한 사용자만 추천한다.

## 등록

1. 최신 APK에서 요리 찾기 화면 상단의 배지 아이콘(테스트 등록 ID)을 누른다. 이 동작은 익명 인증과 본인 등록 코드 조회만 수행하고 모델을 호출하지 않는다.
2. 복사한 64자리 등록 코드를 운영자에게 전달한다. 이는 서버 HMAC 가명값이며 access token이나 OpenAI 키가 아니다.
3. 운영자는 허가한 설치임을 확인하고 프로젝트 SQL 관리 경로에서 다음과 같이 추가한다. 코드는 정규식 `^[a-f0-9]{64}$`를 만족해야 한다. 클라이언트에서 테이블/RPC를 호출해 스스로 등록할 수 없다.

```sql
insert into recipe_private.pilot_testers(user_hash, expires_at)
select 'REPLACE_WITH_64_HEX_REGISTRATION_CODE', expires_at
from recipe_private.pilot_program where singleton
on conflict(user_hash) do update set enabled=true, expires_at=excluded.expires_at;
```

권한 회수: 동일한 코드로 `enabled=false`를 설정한다. 이후 발급·생성·조회 모두 차단된다. 재설치 등으로 익명 사용자가 달라지면 다시 등록해야 한다. 코드만으로 다른 설치를 인증할 수 없다.

## 한도와 종료

테스트 프로그램은 생성 후 24시간(한국 시간 2026-11-09 21:12 만료), 누적 $0.90으로 설정했다. 일반 사용자의 공유 APK만으로는 추천할 수 없다. 사용자가 증액한 총 $1 테스트 허용 중 $0.10은 이전 호출 및 불확실한 비용 여유로 남긴다. 현재 사용자에게 공개 서비스 예산을 승인받은 것은 아니다.

입력/출력 단가는 공식 모델 문서 https://developers.openai.com/api/docs/models/gpt-4.1-mini 에서 2026-11-07 확인한 $0.40/$1.60 per 1M tokens를 적용했다. 요청당 $0.07 선점, 전체 동시 1건, 세션별 동시1/한국 날짜 하루5회 이하다. 사용량이 불명확하면 예약액 전체를 차감한다. 예산은 날짜 변경·테스터 추가·Edge 재배포로 초기화되지 않는다. 테스트 프로그램은 자동 연장하지 않으며 관리자도 기존 행의 시작/만료 연장·예산 증액은 차단된다. 재설정은 별도 운영 승인을 거쳐야 한다.

테스트 모드는 신뢰가 검증되지 않은 IP 헤더를 사용하지 않고, Auth 검증된 등록 사용자 가명에 분당 30회 제한을 건다. 등록 코드 발급은 사용자당 분10회다. 이는 공개 남용 방지 완성이라는 뜻이 아니다. Auth 익명 가입 자체 한도는 별도로 유지한다. 공개 모드는 기존 정책 승인·IP 신뢰 경계 검증이 필요하다.

즉시 중지: DB config.enabled=false와 RECIPE_ENABLED=false를 적용한다. 진행 중 호출 취소/환불은 보장하지 않는다. 테스터 목록 만료·프로그램 만료 또는 권한 회수도 신규 추천을 차단한다.

## 검증

실제 Flutter client + 로컬 SQLite에서 등록전 거절, 운영자 임시 등록, Supabase Auth/issue/reserve/OpenAI/finish 및 Dart 응답 검증, 같은 결과 재조회, 등록 회수 후 거절을 확인했다. 임시 사용자는 회수했다. 현재 허용된 테스트 사용자는 없다.

추천 작업1건 complete, DB 정산676 micro USD($0.000676). 모델은 교정을 포함해 최대2회 호출 가능하다. 이번 실제 호출 횟수·개별 토큰 사용량은 DB에 저장하지 않으므로 정확한 모델 호출 수/청구액까지 확정하지 않는다. 모델 생성 실측과 실제 Android 화면/업데이트 설치 QA는 구분한다.

기본 테스트는 실제 네트워크 호출을 하지 않는다. `test/recipe_live_test.dart`는 RECARE_LIVE_TEST=true를 명시할 때만 실행하며, 운영자가 등록/회수 신호를 조율하는 테스트다. 실제 기기 업데이트 설치와 재고 유지 검증은 아직 남아 있다. 비밀키·토큰·서명키·암호는 로그나 문서에 넣지 않는다.


## 1.2.1 메뉴 우선 추천

첫 화면에는 메뉴명만 3~5개 제안하고, 선택한 메뉴의 상세를 새 단계로 생성한다. 조건이 부족하면 더 적게 제안할 수 있다. 처음 메뉴를 보는 것과 선택 상세 생성은 각각 작업1회로 기존 한국 날짜 하루5회 한도에 포함한다. 동일 단계 재조회와 생성된 상세 재열람은 추가 호출/차감이 없다. 따라서 하루 완성 세트 최대2건+메뉴1건이다.

2026-11-08 실제 Flutter client: 두부/양파/달걀로 두부조림·양파달걀볶음·두부전의 메뉴3개를 받고 두부조림 상세 생성 성공. 메뉴395/36토큰(입력/출력), 상세676/428토큰. 각 모델호출1회, 총2회. 가격 기준 정산216+956=1172 micro USD($0.001172); 실제 청구액은 별도다. 양 단계 재조회 성공, 합성 테스터는 즉시 회수했다. 실프로그램 누적 정산액5304 micro USD($0.005304)는 기존사용분을 포함한다.

테스트 총한도는 사용자 승인으로 $1로 올렸다. 시작시각·기존 작업 비용·기존 테스터는 보존하고 프로그램 예산만$0.90, 별도 과거 호출 여유$0.10으로 구성했다. 새 기능 검증을 위해 만료를24시간 연장했으며 자동으로 연장하지 않는다. 공개 이용은 계속 차단한다.
