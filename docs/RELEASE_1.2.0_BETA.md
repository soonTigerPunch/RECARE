# RE:CARE 1.2.0 beta 1

테스트용 사전 릴리스. 앱 ID는 com.detabev.recare, versionCode는 7입니다.
기존 1.1.1(versionCode 6)과 동일한 원본 인증서를 확인한 APK만 배포합니다.

## 포함된 기능

재고 기반 레시피 입력, 최근 추천, 로컬 즐겨찾기, 장보기 연결, 조리 후 일괄 먹음 기록.
새 Supabase 프로젝트 연결 및 자동 정리 작업 구성.

## 온라인 추천 상태

공개 온라인 추천은 비활성입니다. 앱에서 새 AI 추천을 받으려면 운영 예산·개인정보 안내·남용 방지와 IP 신뢰 경계 검증이 추가로 필요합니다.
현재 APK에서 새 추천이 동작한다고 안내하지 않습니다. 기존 재고·장보기 기능은 사용할 수 있습니다.
Supabase의 OPENAI_API_KEY로 임시 비공개 테스트 함수에서 실제 생성 및 서버 결과 검증은 성공했습니다.
이는 공개 Auth/예약/정산 흐름의 전체 검증이나 실기기 QA 완료를 의미하지 않습니다.

## 설치 주의

원본 키가 없으면 release 빌드를 중단합니다. 기존 앱 삭제나 데이터 초기화를 요구하지 않습니다.
다른 인증서로 설치된 테스트 APK에는 업데이트 호환을 보장할 수 없습니다.
