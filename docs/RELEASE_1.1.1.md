## RE:CARE 1.1.1 · 사용성 업데이트

이전 공개 버전 1.0.3에서 소비기한 확인, 장보기, 여러 재료 등록, 실행 취소 기능을 추가했습니다.

- 소비기한 3일 전·1일 전·당일, 앱 실행 또는 알림 진입 시 소비량 확인
- 여러 임박 재료를 **한 팝업**에 표시하고 재료별 남은 기한·재고 표시
- 절반·1/3·2/3·전부·아직 안 먹음 선택, 저장 전 수량 확인, 오늘 건너뛰기
- 빠른 먹음·폐기와 8초 실행 취소, 여러 재료 등록, 장보기 구매 등록
- Android 선택형 일일 알림, 폐기 사유와 주간 인사이트
- README 전면 개편 및 iOS 프로젝트·macOS 컴파일 자동화 추가

## Android 설치

`RECARE-1.1.1-android.apk` · 버전 1.1.1(6) · Android 10 이상.
release 모드로 빌드한 **테스트 서명 APK**입니다. 정식 스토어 배포본이 아닙니다.

**기존 1.0.3 APK와 서명 키가 달라 덮어쓰기 업데이트가 불가능합니다.**
앱을 삭제하면 저장한 기록이 사라집니다. 기록 보존이 필요하면 기존 앱을 삭제하지 말고 새 테스트 기기에서 확인해 주세요. 기존 데이터를 유지하는 업데이트 배포에는 이전 서명 키가 필요합니다.
첨부한 SHA256SUMS.txt로 파일 무결성을 확인할 수 있습니다.

## iPhone 배포 상태

iOS 15 이상용 프로젝트를 준비했지만 **설치 가능한 IPA/TestFlight 배포는 아직 없습니다.**
Apple 개발자 팀·인증서·프로비저닝 설정이 필요합니다. macOS CI의 unsigned 산출물은 설치파일이 아닙니다.
iOS 예약 알림은 아직 미지원입니다. 자세한 절차는 저장소의 docs/IOS_DISTRIBUTION.md를 참고해 주세요.
